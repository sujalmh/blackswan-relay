# frontend

React + ethers/viem UI for the demo.

- Three rescuer panels (commit privately, show only aggregate).
- Vault trigger state ("protocol enters the danger zone").
- Result state: `RescueTargetMet` on the honest path, on-chain rejection on the cheat path.
- A toggle to show the public-rescue comparison path (leaks amounts) vs the BlackSwan path.

No feature creep beyond the demo flow. This is a demo surface for judges, not a product.
